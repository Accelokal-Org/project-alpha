# Deskonekt app icon submissions

Place the Deskonekt app icon files in this folder.

Useful source files include:
- An SVG master, if available.
- A high-resolution square PNG, preferably with a transparent background.
- Any light-background, dark-background, or small-size variants.
- Existing favicon (`.ico`) or Apple touch icon exports, if available.

Use descriptive filenames such as `deskonekt-icon.svg`,
`deskonekt-icon-1024.png`, or `deskonekt-icon-dark.png`.
Submit the files you already have; every variant is optional.

This folder holds original submissions. Adding files here does not automatically
change the app icon. Reviewed assets can later be integrated into the app's
metadata and interface.

## Applied assets

- `app_icon_light.png` → `public/brand/deskonekt-icon-light.png`: workspace header.
- `app_icon_dark.png` → `public/brand/deskonekt-icon-dark.png`: sign-in branding.
- `icon:favicon.png` → `app/icon.png`: browser favicon, registered through Next.js metadata conventions.

These are unchanged copies of the supplied artwork. The banner and horizontal
lockup variants remain available here for future brand surfaces.
